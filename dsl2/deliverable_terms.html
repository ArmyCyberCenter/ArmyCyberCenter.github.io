Executive Summary

This glossary defines 29 critical technical terms across four key areas: Project Management, Data & Migration, Testing & Deployment, and Infrastructure & Security. Each term includes precise Thai definitions with English references and specifies exact PGE deliverables required for สตง. (State Audit Office), PDPA, and Cloud First compliance.

Executive Summary

Project Overview

The DSL2 system upgrade represents a critical modernization effort for the Student Loan Fund, involving the migration of 4.5 million borrower accounts to a new, cloud-enabled platform with enhanced Krungthai Bank integration.

Compliance Framework

All deliverables must adhere to three key compliance frameworks: State Audit Office (สตง.) requirements, Personal Data Protection Act (PDPA), and the government's Cloud First policy.

Key Deliverables

  • Audit-grade technical documentation
  • Compliance evidence matrices
  • Security assessment reports
  • Data migration validation protocols
